# 메타 투어 매홀 (나와 만나는 학교)

매홀중학교를 소개하는 **ZEP 스타일 2.5D 픽셀 메타버스**예요. p5.js로 만들었고, 티처블 머신(얼굴 인식 · 동작 인식)을 연결할 수 있어요.

```
시작 화면 → 캐릭터 선택 → 운동장 → 복도 → 급식실 ↓ 복도 ↓ 체육관 ← 복도 ← 도서관 ↓ 복도 ↓ 교실(퀴즈 존)
```

- 앞 구역의 NPC 소개를 끝까지 들어야 **다음 문이 열려요.** (노랑/검정 줄무늬 문 = 잠김)
- 4곳 소개를 모두 끝내야 교실(퀴즈 존)에 들어갈 수 있어요.
- 교실 퀴즈 존에서 반장에게 말을 걸면 객관식 퀴즈가 시작돼요.

---

## 1. 실행하는 방법

카메라(티처블 머신)는 **`http://localhost` 또는 `https://` 로 열었을 때만** 켜져요. 그래서 작은 서버를 켜서 여는 걸 추천해요.

| 방법 | 설명 |
|---|---|
| **start_server.bat** (Windows) | 더블클릭하면 서버가 켜지고 브라우저가 열려요. 파이썬 필요 |
| **start_server.sh** (Mac·Linux) | 터미널에서 `sh start_server.sh` |
| VS Code → Live Server | `index.html` 우클릭 → *Open with Live Server* |
| `index.html` 더블클릭 | 키보드/마우스로 하는 건 되지만, 카메라는 안 켜질 수 있어요 |

## 2. 조작 방법

| 동작 | 키 |
|---|---|
| 이동 | `W A S D` 또는 방향키 |
| 대화 넘기기 · 선택 | `Space` · `Enter` · `E` 또는 마우스 클릭 |
| 퀴즈 답 고르기 | `1 2 3 4` 또는 `↑ ↓` + `Space` 또는 클릭 |
| 설정 | `Esc` / 소리 켜기·끄기 `M` |

> 주소 끝에 `?unlock` 을 붙이면(예: `http://localhost:8000/?unlock`) 소개를 건너뛰고 모든 문이 열려요. 발표 연습할 때 편해요.

## 3. 폴더 안에 뭐가 있나요? (파일이 많지 않아요!)

```
maehol-meta/
│
├─ index.html      ← 이 파일을 열면 게임이 시작돼요
├─ config.js       ← ★ 설정: 티처블 머신 링크, 걷는 속도     (직접 고치는 파일)
├─ content.js      ← ★ 소개 대사 + 퀴즈                      (직접 고치는 파일)
├─ sketch.js       ← 게임의 시작점 (p5.js의 setup / draw)
│
├─ game/           ← 게임 코드. 번호 순서대로 읽어 보세요
│   ├─ 1_basics.js     공용 도구: 이미지 불러오기, 키보드 입력, 효과음
│   ├─ 2_world.js      맵, 충돌(벽에 막히기), 잠긴 문, 카메라, 그리기
│   ├─ 3_ui.js         버튼, 이름표, 대화창, 알림, 설정 창
│   ├─ 4_screens.js    시작 화면 + 캐릭터 선택 화면
│   ├─ 5_play.js       게임 화면: 대화, 문 열기, 퀴즈, 화면 정보(HUD)
│   ├─ 6_teachable.js  티처블 머신(얼굴/동작 인식) 연결
│   └─ map_data.js     맵 데이터 (자동으로 만들어져요. 직접 고치지 마세요)
│
├─ assets/         ← 픽셀아트 그림들 (안에 안내 파일이 있어요)
│   ├─ sprites/        캐릭터와 NPC (한 명당 그림 한 장)
│   ├─ objects/        가구, 소품, 벽 장식, 문 (하나당 그림 한 장)
│   ├─ portraits/      대화창/선택 카드에 쓰는 얼굴 그림
│   ├─ backgrounds/    맵 전체 배경, 시작 화면
│   └─ ui/             말풍선, 자물쇠, 별 같은 아이콘
│
├─ lib/            ← 남이 만든 도구들 (p5.js, 티처블 머신). 고치지 않아도 돼요
├─ fonts/          ← 한글 픽셀 글꼴 (Galmuri)
└─ tools/          ← (선택) 그림과 맵을 코드로 만드는 파이썬 도구
```

**처음 코딩을 본다면 이 순서로 읽어 보세요:** `config.js` → `content.js` → `sketch.js` → `game/1_basics.js` → `game/5_play.js`

## 4. 학교 소개 대사와 퀴즈 넣기 ★

`content.js` 파일 하나만 고치면 돼요. 파일 안에 설명이 적혀 있어요.

- **대사**: NPC가 하는 말. 따옴표 `" "` 안의 글자를 바꾸세요. 줄을 더하거나 빼도 돼요.
- **퀴즈**: 문제, 보기, 정답 번호(`answer`, 0이 첫 번째), 해설을 바꾸세요. 문제 수도 자유예요.

> 지금 들어 있는 건 동작을 확인하려고 넣은 **임시 내용**이에요.

## 5. 티처블 머신 연결

`config.js` 를 열어 링크 칸에 모델 주소를 붙여 넣으세요. **비워 두면 키보드/마우스로 플레이해요.**

```js
TM_FACE_MODEL_URL: "",     // 얼굴 인식 모델 (캐릭터 선택)
TM_MOTION_MODEL_URL: "",   // 동작 인식 모델 (캐릭터 이동)
```

**얼굴 인식**: 클래스 이름을 **동훈 / 민성 / 성민 / No one** 으로 만들어 주세요.

| 클래스 | 결과 |
|---|---|
| 동훈 · 민성 · 성민 | 그 캐릭터가 골라져요 |
| **No one** | 사람이 없다는 뜻 → 아무것도 고르지 않고 "얼굴이 보이지 않아요" 표시 |

- 확률이 80% 이상이어야 인식으로 쳐요. 같은 얼굴이 1.8초 유지되면 자동으로 시작해요.
- `FACE_LIVE_IN_GAME: true` 로 바꾸면 게임 중에도 얼굴을 바꾸면 캐릭터가 따라 바뀌어요.

**동작 인식**: 클래스 이름은 `config.js` 의 `MOTION_CLASSES` 에서 정해요. (기본: 위 / 아래 / 왼쪽 / 오른쪽 / 확인)

**카메라 없이 시험하기**: 브라우저 개발자 도구(F12) 콘솔에 입력해요.
```js
MH.TM.debug.face("민성", 0.95)      // 민성으로 인식된 것처럼
MH.TM.debug.face("No one", 0.99)    // 사람이 없는 것처럼
MH.TM.debug.motion("오른쪽", 0.95)  // 오른쪽 동작처럼 (캐릭터가 오른쪽으로 걸어요)
```

## 6. 이렇게 바꿔 보세요 (코딩 연습)

| 하고 싶은 일 | 어디를 고치나요? |
|---|---|
| 걷는 속도 바꾸기 | `config.js` 의 `PLAYER_SPEED` |
| 대화 글자가 나오는 속도 | `config.js` 의 `TEXT_SPEED` |
| 퀴즈 결과 문구 바꾸기 | `game/5_play.js` 의 `drawResult` 안 `msg` |
| 효과음 바꾸기 | `game/1_basics.js` 의 `Sfx` 안 숫자들 |
| 버튼/상자 색 바꾸기 | `game/3_ui.js` 의 색깔 글자 (예: `"#ffd34a"`) |
| 캐릭터 카드 설명 바꾸기 | `game/4_screens.js` 의 `CHARS` |
| 소개를 들어야 하는 구역 순서 | `game/5_play.js` 의 `AREA_ORDER` |

## 7. 그림이나 맵을 바꾸고 싶을 때

- `assets/` 안의 PNG를 직접 그린 그림으로 **바꿔 끼워도 돼요.** (파일 이름과 크기는 그대로)
- 방 모양, 가구 위치, NPC 위치, 잠긴 문 조건은 파이썬 도구로 바꿔요. 자세한 건 `tools/README.txt` 를 보세요.
