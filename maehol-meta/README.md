# 메타 투어 매홀 (나와 만나는 학교)

매홀중학교를 소개하는 **ZEP 스타일 2.5D 픽셀 메타버스**예요. p5.js로 만들었고, 티처블 머신(얼굴 인식 · 동작 인식)을 연결할 수 있어요.

```
시작 화면 → 캐릭터 선택 → 운동장 → 복도 → 급식실 ↓ 복도 ↓ 체육관 ← 복도 ← 도서관 ↓ 복도 ↓ 교실(퀴즈 존)
```

- 앞 구역의 NPC 소개를 끝까지 들어야 **다음 문이 열려요.** (노랑/검정 줄무늬 문 = 잠김)
- 운동장·급식실·체육관·도서관 소개를 **모두** 끝내야 교실(퀴즈 존)에 들어갈 수 있어요.
- 교실 퀴즈 존에서 반장에게 말을 걸면 객관식 퀴즈가 시작돼요.

## 1. 실행하는 방법

브라우저 보안 때문에 **웹캠(티처블 머신)은 `https://` 또는 `http://localhost` 에서만** 켜져요. 아래 중 편한 방법을 쓰세요.

| 방법 | 설명 |
|---|---|
| **start_server.bat** (Windows) / **start_server.sh** (Mac·Linux) | 더블클릭하면 작은 서버가 켜지고 브라우저가 열려요. (파이썬이 필요해요) |
| VS Code → Live Server | `index.html` 에서 우클릭 → *Open with Live Server* |
| GitHub Pages / 학교 서버 | 폴더 전체를 올리면 돼요 |
| `index.html` 더블클릭 | 키보드·마우스 플레이는 되지만, 카메라는 안 켜질 수 있어요 |

> p5.js 웹 에디터에 올릴 때는 폴더 전체(`index.html`, `sketch.js`, `config.js`, `js/`, `data/`, `assets/`, `fonts/`, `lib/`)를 그대로 업로드하세요.

## 2. 조작 방법

| 동작 | 키 |
|---|---|
| 이동 | `W A S D` 또는 방향키 (화면 기준 위·아래·왼쪽·오른쪽) |
| 대화 넘기기 · 선택 | `Space` · `Enter` · `E` 또는 마우스 클릭 |
| 퀴즈 답 고르기 | `1` `2` `3` `4` 또는 `↑ ↓` + `Space` 또는 클릭 |
| 설정 / 도움말 | `Esc` |
| 소리 켜기·끄기 | `M` |

주소 뒤에 `?unlock` 을 붙이면(예: `http://localhost:8000/?unlock`) 소개를 건너뛰고 모든 문이 열려요. 발표 연습이나 시험할 때 편해요.

## 3. 학교 소개 대사와 퀴즈 넣기  ★

- `data/script.js` : NPC 소개 대사. **지금 들어 있는 건 임시 대사**예요. `lines` 안의 문장을 학교 소개로 바꾸세요. 문장은 몇 개든 늘리거나 줄여도 돼요.
- `data/quiz.js` : 퀴즈 문제. 문제 수도 자유예요. `answer` 는 정답 번호예요(0이 첫 번째 보기).

두 파일만 고치면 돼요. 다른 파일은 건드리지 않아도 돼요.

## 4. 티처블 머신 연결

`config.js` 를 열어 링크 칸에 모델 주소를 붙여 넣으세요. **비워 두면 키보드/마우스로 플레이해요.**

```js
TM_FACE_MODEL_URL: "",     // 얼굴 인식 모델 (캐릭터 선택)
TM_MOTION_MODEL_URL: "",   // 동작 인식 모델 (캐릭터 이동)
TM_MOTION_TYPE: "pose",    // "pose"(포즈 프로젝트) 또는 "image"(이미지 프로젝트)
```

### 얼굴 인식 (캐릭터 선택)
클래스 이름을 **동훈 / 민성 / 성민 / No one** 으로 만들어 주세요. (사진 순서: 동훈 → 민성 → 성민)

| 티처블 머신 클래스 | 결과 |
|---|---|
| 동훈 | 동훈 캐릭터 선택 |
| 민성 | 민성 캐릭터 선택 |
| 성민 | 성민 캐릭터 선택 |
| **No one** | 사람이 없어요 → 아무것도 선택하지 않고 "얼굴이 보이지 않아요" 표시 |

- 확률이 `FACE_MIN_PROB`(기본 80%) 이상이어야 인식으로 쳐요.
- 같은 얼굴이 `FACE_HOLD_MS`(기본 1.8초) 동안 유지되면 자동으로 시작해요. 키보드/클릭으로 바로 시작해도 돼요.
- `FACE_LIVE_IN_GAME: true` 로 바꾸면 게임 중에도 얼굴이 바뀌면 캐릭터가 따라 바뀌어요.

### 동작 인식 (캐릭터 이동)
클래스 이름은 `config.js` 의 `MOTION_CLASSES` 에서 바꿀 수 있어요. (기본: 위 / 아래 / 왼쪽 / 오른쪽 / 확인, 쉬는 자세는 정지·No one)

### 카메라 없이 흉내 내서 시험하기
브라우저 개발자 도구(F12) 콘솔에서:
```js
MH.TM.debug.face("민성", 0.95)     // 얼굴 인식 결과를 흉내
MH.TM.debug.face("No one", 0.99)   // 사람 없음
MH.TM.debug.motion("오른쪽", 0.95) // 동작 인식 결과를 흉내 (오른쪽으로 걸어가요)
```

## 5. 폴더 구조

```
index.html      게임 페이지
sketch.js       p5.js 시작점(불러오기 → 장면 전환)
config.js       티처블 머신 링크, 클래스 이름, 속도 설정
data/           script.js(소개 대사) · quiz.js(퀴즈)   ← 직접 고치는 파일
js/             게임 코드 (world.js 월드/충돌/문, scene_*.js 화면, tm.js 티처블 머신 ...)
js/data/        map.js(맵 배치·충돌) · assets.js(이미지 목록)   ← 자동 생성 파일
assets/
  sprites/      캐릭터·NPC 스프라이트  <이름>/<방향>_<프레임>.png   (4방향 × 3프레임)
  objects/      가구·소품·벽 장식·문 이미지 (한 개당 PNG 하나)
  portraits/    선택 카드/대화창 얼굴 그림
  backgrounds/  map.png(바닥+벽 전체 지도) · title.png(시작 화면)
  ui/           말풍선, 자물쇠, 별 같은 아이콘
fonts/          Galmuri(한글 픽셀 폰트, OFL 라이선스)
lib/            p5.js, TensorFlow.js, 티처블 머신 라이브러리 (인터넷 없이도 로드돼요)
tools/          픽셀아트·맵을 코드로 만드는 파이썬 스크립트
```

## 6. 이미지/맵을 고치고 싶을 때

모든 픽셀아트는 `tools/` 의 파이썬 코드로 그려요. (Python 3 + Pillow 필요: `pip install pillow`)

```
python tools/make_assets.py
```

| 파일 | 고칠 수 있는 것 |
|---|---|
| `tools/chars.py` | 캐릭터·NPC 모습(머리 모양, 안경, 모자, 색) |
| `tools/objects.py` | 가구·소품·벽 장식 그림 |
| `tools/mapbuild.py` | 방 위치와 크기, 가구 배치, NPC 위치, 잠긴 문 조건 |

- 이미지 파일(`assets/…png`)을 직접 그린 그림으로 **바꿔 끼워도 돼요.** (파일 이름과 크기만 같게)
- NPC 이름·위치는 `tools/mapbuild.py` 의 `NPCS` 에서 바꾸고 다시 `make_assets.py` 를 실행하세요.

## 7. 알아 둘 점

- 학교의 실제 모습(교훈, 급식 시간 등)은 `data/script.js` · `data/quiz.js` 에서 직접 넣어 주세요.
- 가슴 배지는 학교 마크를 몰라서 단순한 원형 배지로 그렸어요.
- 글꼴 Galmuri는 SIL Open Font License 1.1 로 배포돼요. (`tools/fonts/Galmuri-LICENSE-OFL.md`)
