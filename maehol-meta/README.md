# 메타 투어 매홀 (나와 만나는 학교)

매홀중학교를 소개하는 **ZEP 스타일 2.5D 픽셀 메타버스**예요. p5.js로 만들었고, 티처블 머신(얼굴 인식 · 동작 인식)을 연결할 수 있어요.

```
시작 화면 → 캐릭터 선택 → 운동장 → (본관 입구) 복도 → 급식실 → 복도 → 체육관 → 복도 → 도서관 → 복도 → 교실(퀴즈 존)
```
- 앞 구역의 NPC 소개를 끝까지 들어야 **다음 문이 열려요.** (노랑/검정 줄무늬 문 = 잠김)
- 복도마다 있는 학생(민준·채원·서진·다은)에게 말을 걸면 학교 이야기(연혁, 교훈, 상징, 학년별 층 …)를 들려줘요. (필수는 아니에요)
- 4곳 소개를 모두 끝내야 교실(퀴즈 존)에 들어갈 수 있고, 반장에게 말을 걸면 객관식 퀴즈가 시작돼요.

## 1. 실행하기
카메라(티처블 머신)는 **`http://localhost` 또는 `https://`** 에서만 켜져요. 그래서 작은 서버로 여는 걸 추천해요.
- **Windows**: `start_server.bat` 더블클릭 (파이썬 필요)
- **Mac·Linux**: 터미널에서 `sh start_server.sh`
- **VS Code**: `index.html` 우클릭 → *Open with Live Server*
- `index.html` 을 그냥 더블클릭해도 키보드/마우스로는 플레이할 수 있어요.

| 조작 | 키 |
|---|---|
| 이동 | `W A S D` 또는 방향키 |
| 대화 · 선택 | `Space` · `Enter` · `E` 또는 클릭 |
| 퀴즈 답 | `1 2 3 4` 또는 `↑ ↓` + `Space` 또는 클릭 |
| 설정 / 소리 | `Esc` / `M` |

주소 끝에 `?unlock` 을 붙이면(`http://localhost:8000/?unlock`) 소개를 건너뛰고 모든 문이 열려요. 발표 연습용이에요.

## 2. p5.js 웹 에디터(editor.p5js.org)에 올리기
`p5editor/` 폴더(또는 `p5editor.zip`)에 **폴더 구분 없이 파일 5개**를 만들어 두었어요. 이 5개를 한 번에 올리면 돼요.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀 |
| `sketch.js` | 게임 코드 |
| `content.js` | ★ 직접 고침: 설정(티처블 머신 링크) + 소개 대사 + 퀴즈 |
| `data.js` | 맵 데이터 + 도트 글꼴 (자동으로 만들어져요) |
| `art.png` | 맵 배경, 시작 화면, 가구·캐릭터·아이콘 그림을 한 장으로 묶은 것 |

1. https://editor.p5js.org 에서 로그인 → 파일 ▸ 새로 만들기
2. 왼쪽 'Sketch Files' 의 기본 파일 `index.html`, `sketch.js` 를 **먼저 삭제** (이름 옆 ▸ Delete). 같은 이름은 덮어쓰기가 안 되고 `sketch-1.js` 처럼 이름만 바뀌어 올라가기 때문이에요. `style.css` 는 그냥 둬도 돼요.
3. 'Sketch Files' 옆 ▸ → **Upload file** → 5개 파일을 모두 선택해서 올리기 (한 번에 최대 6개까지 올라가요)
4. ▶ 눌러서 실행

- 대사와 퀴즈는 에디터에서 `content.js` 를 열어 고치고 ▶ 를 다시 누르면 돼요.
- 티처블 머신 라이브러리는 인터넷 주소로 불러와요. 카메라는 미리보기에서 권한을 '허용'해야 켜져요.
- 이 꾸러미는 `python tools/make_assets.py`(또는 `python tools/make_p5editor.py`)를 실행하면 최신 그림·대사로 다시 만들어져요.
- 낱개 PNG 그림은 `assets/objects/` 에 그대로 있어요. 웹 에디터용 `art.png` 안에는 같은 그림이 묶여 있어요.

## 3. 폴더 안에 뭐가 있나요?
```
index.html     ← 이 파일을 열면 게임이 시작돼요
sketch.js      ← 게임 코드 전부 (차례가 적혀 있어요)
config.js      ← ★ 직접 고침: 티처블 머신 링크, 걷는 속도
content.js     ← ★ 직접 고침: 소개 대사 + 퀴즈
map_data.js    ← 맵 데이터 (자동으로 만들어져요. 직접 고치지 마세요)
assets/        ← 픽셀아트 그림
lib/  fonts/   ← 남이 만든 도구(p5.js 등), 한글 픽셀 글꼴
p5editor/      ← p5.js 웹 에디터에 올리는 꾸러미 (파일 5개, 폴더 구분 없음)
tools/         ← (선택) 그림과 맵을 만드는 파이썬 도구
```
**코드 읽는 순서:** `config.js` → `content.js` → `sketch.js` (맨 위 차례 참고)

### assets 폴더 (게임의 모든 그림)
| 폴더 | 내용 |
|---|---|
| `sprites/` | 캐릭터와 NPC. **한 명당 PNG 한 장**이고, 한 장 안에 여러 모습이 들어 있어요. 가로 3칸 = 걷는 모습(서 있기·왼발·오른발), 세로 4줄 = 방향(앞·왼쪽·오른쪽·뒤), 칸 하나는 30×46 픽셀 |
| `objects/` | 가구, 소품, 벽 장식, 문. **하나당 PNG 한 장** (예: `desk.png`, `chair_red_n.png`, `window_3_field.png`, `gate_v_closed.png`) |
| `backgrounds/` | `map.png` = 맵 전체 배경(바닥+벽), `title.png` = 시작 화면 |
| `ui/` | 말풍선, 자물쇠, 별 같은 작은 아이콘 |

> 같은 파일 이름·크기의 PNG(배경 투명)로 바꿔 끼우면 직접 그린 그림을 쓸 수 있어요.

## 4. 학교 소개 대사와 퀴즈 넣기 ★
`content.js` 파일 하나만 고치면 돼요. 파일 안에 설명이 적혀 있어요.
- **대사**: 따옴표 `" "` 안의 글자를 바꾸세요. 줄을 더하거나 빼도 돼요.
- **퀴즈**: 문제, 보기, 정답 번호(`answer`, 0이 첫 번째), 해설. 문제 수도 자유예요.

> 복도 이야기와 급식실 대사는 실제 매홀중학교 내용이에요. 운동장·체육관·도서관 대사와 일부 퀴즈는 아직 **임시 내용**이에요.

## 5. 티처블 머신 연결
`config.js` 의 링크 칸에 모델 주소를 붙여 넣으세요. **비워 두면 키보드/마우스로 플레이해요.**
```js
TM_FACE_MODEL_URL: "",     // 얼굴 인식 모델 (캐릭터 선택)
TM_MOTION_MODEL_URL: "",   // 동작 인식 모델 (캐릭터 이동)
```
**얼굴 인식** — 클래스 이름을 **동훈 / 민성 / 성민 / No one** 으로 만들어 주세요.
| 클래스 | 결과 |
|---|---|
| 동훈 · 민성 · 성민 | 그 캐릭터가 골라져요 |
| **No one** | 사람이 없다는 뜻 → 아무것도 고르지 않고 "얼굴이 보이지 않아요" 표시 |

확률이 80% 이상이어야 인식으로 쳐요. 같은 얼굴이 1.8초 유지되면 자동으로 시작해요.
**동작 인식** — 클래스 이름은 `config.js` 의 `MOTION_CLASSES` 에서 정해요. (기본: 위 / 아래 / 왼쪽 / 오른쪽 / 확인)

**카메라 없이 시험하기** — 브라우저 개발자 도구(F12) 콘솔에 입력하세요.
```js
debugFace("민성")        // 민성으로 인식된 것처럼
debugFace("No one")      // 사람이 없는 것처럼
debugMotion("오른쪽")    // 오른쪽 동작처럼 (캐릭터가 오른쪽으로 걸어요)
```

## 6. 이렇게 바꿔 보세요 (코딩 연습)
| 하고 싶은 일 | 어디를? |
|---|---|
| 걷는 속도 / 글자 속도 | `config.js` 의 `PLAYER_SPEED` / `TEXT_SPEED` |
| 퀴즈 결과 문구 | `sketch.js` 에서 `만점이에요` 를 검색 |
| 효과음 | `sketch.js` 의 `SOUNDS` 안 숫자들 |
| 버튼·상자 색 | `sketch.js` 의 `BLUE`, `PINK`, `GRAY`, 색깔 글자(`"#ffd34a"`) |
| 캐릭터 카드 설명 | `sketch.js` 의 `CHARS` |
| 소개를 들어야 하는 구역 순서 | `sketch.js` 의 `AREAS` |

## 7. (선택) 그림과 맵 다시 만들기 — tools 폴더
게임을 하는 데는 필요 없어요. 방 모양, 가구·NPC 위치, 잠긴 문 조건을 바꾸고 싶을 때만 쓰세요.
준비: 파이썬 3, `pip install pillow` / 실행: `python tools/make_assets.py`


| 파일 | 하는 일 |
|---|---|
| `mapbuild.py` | ★ 방 위치·크기, 가구 배치, NPC 위치(`NPCS`), 잠긴 문 조건(`GATES`) |
| `art.py` | 가구·소품·벽 장식(창문, 칠판, 문 …) 그림 그리기. 색은 파일 위쪽 색 모음에서 바꿔요 |
| `chars.py` | 캐릭터·NPC 그리기 (머리 모양, 안경, 모자, 색) |
| `pxlib.py` | 색, 글씨, 둥근 사각형·그림자 같은 그리기 도구 |
| `make_assets.py` | 위 파일들을 모아 `assets/` 와 `map_data.js` 를 만드는 대장 파일 (`p5editor/` 도 같이 만들어요) |
| `make_p5editor.py` | 웹 에디터용 꾸러미(`p5editor/`)를 만들어요 |
