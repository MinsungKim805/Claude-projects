# 메타 투어 매홀 (나와 만나는 학교)

매홀중학교를 소개하는 **ZEP 스타일 2.5D 픽셀 메타버스**예요. p5.js로 만들었고, 티처블 머신(얼굴 인식 · 동작 인식)을 연결할 수 있어요.

```
시작 화면 → 캐릭터 선택 → 운동장 → (본관 입구) 복도 → 급식실 → 복도 → 체육관 → 복도 → 도서관 → 복도 → 교실(퀴즈)
```
- 앞 구역의 NPC 소개를 끝까지 들어야 **다음 문이 열려요.** (노랑/검정 줄무늬 문 = 잠김)
- 복도마다 있는 학생(민준·채원·서진·다은)에게 말을 걸면 학교 이야기(연혁, 교훈, 상징, 학년별 층 …)를 들려줘요. (필수는 아니에요)
- 새로운 장소(본관 복도 · 급식실 · 체육관 · 도서관 · 교실)에 **처음 들어가면 그 장소 사진**이 반짝이는 효과와 함께 잠깐 나왔다가 사라져요. (Space · 클릭하면 바로 넘어가요) 복도는 처음 만나는 본관 복도에서만 나와요.
- 4곳 소개를 모두 끝내야 교실에 들어갈 수 있어요. 교실 앞쪽 **교탁 바로 앞 책상**(머리 위에 `!` 표시)에 가서 `Space` 로 **앉으면 [퀴즈 시작하기] 버튼**이 나와요. 반장에게 말을 걸면 퀴즈 안내를 들을 수 있어요. 일어나려면 `Esc` 나 `↓`, [일어나기] 버튼을 눌러요. 객관식 퀴즈는 8문제예요. 퀴즈를 시작할 때마다 **보기 순서가 무작위로 섞여서 정답 위치가 매번 달라져요.** (문제 순서는 그대로예요. 순서가 중요한 보기는 `content.js` 에서 `fixed: true` 로 고정해요.)

## 1. 게임 파일은 `maehol-meta/` 폴더 안에 딱 6개, 폴더는 없어요
(같은 6개를 묶은 `maehol-meta.zip` 도 맨 위에 있어요.)

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀 (p5.js 를 인터넷에서 불러와요) |
| `sketch.js` | 게임 코드 ① 준비 · 입력 · 꾸미기 도구 · 불러오기 화면 · 시작점 (차례가 적혀 있어요) |
| `game.js` | 게임 코드 ② 월드(맵·충돌) · 티처블 머신 · 시작/캐릭터 선택/게임/퀴즈 화면 |
| `content.js` | ★ **직접 고치는 파일**: 설정(티처블 머신 링크) + 소개 대사 + 퀴즈 |
| `data.js` | 맵 데이터 + 도트 글꼴 (자동으로 만들어져요. 고치지 마세요) |
| `art.png` | 맵 배경, 시작 화면, 가구·캐릭터·아이콘 그림을 **한 장으로 묶은 것** |

맨 위의 `tools/` 폴더는 그림을 다시 그리고 싶을 때만 쓰는 파이썬 도구예요. **게임을 하는 데는 필요 없어요.**

## 2. 실행하기
- **내 컴퓨터에서**: `maehol-meta/` 폴더(또는 zip 을 푼 폴더)의 `index.html` 을 더블클릭해요. (인터넷이 필요해요)
  - 티처블 머신 카메라는 `http://localhost` 또는 `https://` 에서만 켜져요. 폴더에서 `python -m http.server` 를 실행하고 `http://localhost:8000` 으로 열어요.
- **p5.js 웹 에디터(editor.p5js.org)에서**: 아래 3번 순서대로 올려요.

| 조작 | 키 |
|---|---|
| 걷기 | `W A S D` 또는 방향키, 또는 **화면을 누르고 있으면 그쪽으로 걸어가요** |
| 대화 / 확인 | `Space` · `Enter` · `E` 또는 NPC 를 클릭 |
| 캐릭터 고르기 | `1 2 3` 또는 카드를 클릭 |
| 퀴즈 답 | `1 2 3 4` 또는 `↑ ↓` + `Space` 또는 클릭 |
| 설정 | `Esc` 또는 화면의 설정 버튼 |

> **키보드가 안 먹을 때**: 웹 에디터처럼 게임이 작은 창 안에 있으면, 화면을 한 번 클릭해야 키보드가 게임으로 들어와요. (클릭하면 자동으로 맞춰져요.) 그래도 안 되면 화면을 누른 채로 걸으면 돼요.

## 3. p5.js 웹 에디터에 올리기
p5 웹 에디터는 한 번에 6개까지 올릴 수 있어서, `maehol-meta/` 안의 6개 파일을 **한 번에** 올리면 돼요.

1. https://editor.p5js.org 에서 로그인 → 파일 ▸ 새로 만들기
2. 왼쪽 'Sketch Files' 의 기본 파일 `index.html`, `sketch.js` 를 **먼저 삭제** (이름 옆 ▸ Delete). 같은 이름은 덮어쓰기가 안 되고 `sketch-1.js` 처럼 이름만 바뀌어 올라가기 때문이에요. `style.css` 는 그냥 둬도 돼요.
3. 'Sketch Files' 옆 ▸ → **Upload file** → 6개 파일을 모두 선택해서 올리기
4. ▶ 눌러서 실행

- 대사와 퀴즈는 에디터에서 `content.js` 를 열어 고치고 ▶ 를 다시 누르면 돼요.
- 올린 뒤 `art-1.png`, `data-1.js` 처럼 이름이 바뀌어 있으면, 지우고 다시 올려요.
- 에디터는 **80,000바이트 이상인 글자 파일**을 고칠 수 없는 파일로 올려요. 그래서 코드를 `sketch.js` 와 `game.js` 두 파일로 나눠 두었어요. (지금은 각각 32KB · 48KB 쯤이에요) 코드를 더 늘릴 때도 한 파일이 80KB 를 넘지 않게 해 주세요. (도구로 다시 만들 때 `tools/pack.py` 가 79KB 를 넘으면 알려줘요)

> **파일이 안 불러와져도 시작돼요**: 게임이 `data.js`, `art.png`, `content.js` 를 **내 파일 · GitHub · jsDelivr 에서 동시에** 가져와서 먼저 성공한 걸 써요. 에디터가 올린 파일이 안 불러와지거나 오래 걸려도 3초 뒤엔 GitHub 에서 받기 시작해요. (`TypeError … 'collision'` 오류가 나던 이유예요.) 불러오는 화면에 파일마다 어디서 받는 중인지 나와요.
> 단, 내가 고친 대사·맵·그림은 **내 파일이 불러와져야** 반영돼요. GitHub 에서 받은 건 올려 둔 원본이에요.
> 모두 실패하면 **어떤 파일이 왜 안 불러와졌는지**(주소와 이유)가 빨간 글자로 나오고, `내 컴퓨터에서 파일 고르기` 버튼으로 zip 을 푼 폴더의 `content.js`, `data.js`, `art.png` 를 직접 골라 시작할 수도 있어요.
> `index.html` 은 작은 `content.js` 만 불러오고, 큰 파일(`data.js`, 그림)은 게임 코드가 불러와요. 에디터가 큰 파일의 주소를 응답 없이 붙들고 있어도 게임이 멈추지 않게 하려는 거예요.
> `ReferenceError: _LP1 is not defined` 는 에디터의 '반복문 보호' 기능이 중첩된 `for` 문을 잘못 바꿔서 나던 오류예요. 이제 코드에 `for(;;)` · `while` 을 쓰지 않아서(`for...of`, `times(n)` 사용) 나지 않아요. 코드를 고칠 때도 이 두 가지는 쓰지 마세요. (도구로 다시 만들 때 `tools/pack.py` 가 검사해 줘요)

## 4. 학교 소개 대사와 퀴즈 넣기 ★
`content.js` 파일 하나만 고치면 돼요. 파일 안에 설명이 적혀 있어요.
- **대사**: 따옴표 `" "` 안의 글자를 바꾸세요. 줄을 더하거나 빼도 돼요.
- **퀴즈**: 문제, 보기, 정답 번호(`answer`, 0이 첫 번째), 해설. 문제 수도 자유예요.

> `content.js` 에 빠진 것이나 틀린 값(예: 정답 번호가 보기 수보다 큼)이 있으면, 게임이 시작할 때 무엇이 문제인지 알려줘요.
> 복도 이야기와 급식실 대사는 실제 매홀중학교 내용이에요. 운동장·체육관·도서관 대사와 일부 퀴즈는 아직 **임시 내용**이에요.

## 5. 티처블 머신 연결
`content.js` 맨 위의 링크 칸을 채우면 돼요. (비워 두면 키보드/마우스로 플레이해요)

| 칸 | 모델 | 하는 일 |
|---|---|---|
| `TM_FACE_MODEL_URL` | 이미지 프로젝트 | 얼굴 인식 → 캐릭터 선택 (클래스: `동훈` `민성` `성민` `no face`) — **연결됨**: `https://teachablemachine.withgoogle.com/models/IsJukufkt/` |
| `TM_MOTION_MODEL_URL` | 포즈 / 이미지 프로젝트 | 동작 인식 → 캐릭터 이동 |

1. 티처블 머신에서 모델을 **내보내기 ▸ 업로드(공유 가능한 링크)** 해서 링크를 복사해요.
2. 링크를 따옴표 안에 붙여 넣어요. 예) `TM_FACE_MODEL_URL: "https://teachablemachine.withgoogle.com/models/AbCdEfGhI/"`
3. 클래스 이름이 다르면 `FACE_CLASSES`, `MOTION_CLASSES` 를 고쳐요.
4. 얼굴 클래스 이름이 **`no face`** / `No one` (사람이 없을 때)이면 아무 캐릭터도 고르지 않고 기다려요. (`FACE_NONE_CLASSES` 에 적힌 이름)
5. 카메라 권한을 '허용'하면 돼요. 같은 얼굴이 1.8초 동안 보이면 자동으로 시작해요.

> 개발자 도구(F12) 콘솔에서 `debugFace("성민")`, `debugMotion("오른쪽")` 을 입력하면 카메라 없이 인식 결과를 흉내 낼 수 있어요.

## 6. 그림 바꾸기·다시 그리기 (선택) — tools 폴더
방 모양, 가구·NPC 위치, 잠긴 문 조건, 그림 색을 바꾸고 싶을 때만 쓰세요.
준비: 파이썬 3, `pip install pillow` / 실행: `python tools/make_assets.py`  → `maehol-meta/art.png`, `maehol-meta/data.js`, `maehol-meta.zip` 이 새로 만들어져요.

| 파일 | 하는 일 |
|---|---|
| `mapbuild.py` | ★ 방 위치·크기, 가구 배치, NPC 위치(`NPCS`), 잠긴 문 조건(`GATES`) |
| `art.py` | 가구·소품·벽 장식(창문, 칠판, 문 …) 그림 그리기. 색은 파일 위쪽 색 모음에서 바꿔요 |
| `chars.py` | 캐릭터·NPC 그리기 (머리 모양, 안경, 모자, 색) |
| `pxlib.py` | 색, 글씨, 둥근 사각형·그림자 같은 그리기 도구 |
| `pack.py` | 그림들을 `art.png` 한 장으로 묶고 `data.js` 와 zip 을 만들어요 |

장소 사진은 `tools/reference/places/` 안의 `cafeteria` `gym` `library` `classroom` `corr1` (.webp) 예요. 바꾸고 싶으면 같은 이름으로 바꿔 넣고 `make_assets.py` 를 다시 실행하세요. (corr1 은 본관 복도 c1 에서만 나와요)
| `make_assets.py` | 위 파일들을 모아 실행하는 대장 파일 |

낱개 PNG(가구 하나당 그림 한 장)는 도구를 실행하면 `tools/_work/assets/` 에 만들어져요.

> 도구로 `art.png`, `data.js` 를 다시 만들었다면 GitHub 에 올린 뒤, `sketch.js` 위쪽의 `SHA` 값(긴 숫자·영문 커밋 번호)을 새 커밋 번호로 바꿔 주세요. (파일을 못 올린 사람이 인터넷에서 받아 가는 주소예요.)
